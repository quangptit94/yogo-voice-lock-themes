# Yogo AI Voice Lock – themes

Ảnh hình nền màn khoá (1080x2400, WebP) cho app AI Voice Lock Screen.

- `themes/` – ảnh theme, app tải qua link raw:
  `https://gitlab.com/quangnh.ptit/yogo-voice-lock-themes/-/raw/main/themes/<tên file>`
- `themes.json` – danh sách theme theo thứ tự hiển thị trong app.

Thêm theme mới: thêm file vào `themes/` và thêm tên file vào `themes.json` (app đọc danh sách này mỗi lần mở).
Repo phải để **Public** thì app mới tải được.
